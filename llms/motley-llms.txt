# Motley

> Motley builds a governed semantic layer for AI agents and business intelligence. Its open-core product, SLayer (motley-slayer), lets teams model measures, dimensions, and filters once, then have agents and apps generate and run correct SQL across Postgres, MySQL, Snowflake, BigQuery, ClickHouse, and DuckDB — over MCP, REST, CLI, a Python client, Apache Arrow Flight SQL, and a Postgres facade. Motley Cloud adds hosting, OAuth access control, row-level security, versioning, and governed reporting. Zurich-based; backed by Seedcamp.

This llms.txt was generated by the API Evangelist enrichment pipeline from the provider's public developer surface.

## APIs

- [Motley SLayer Semantic Layer](https://docs.motley.ai/slayer/): Model measures/dimensions/filters once; agents query semantically and SLayer compiles + runs the SQL. Base URL https://app.motley.ai/api/v1/ (Motley Cloud).

## Interfaces

- MCP (hosted): https://app.motley.ai/api/v1/mcp
- MCP (local stdio): `uvx --from 'motley-slayer[postgres]' slayer mcp --ingest-on-startup`
- Python / CLI: `pip install motley-slayer` (PyPI) — ships the `slayer` CLI, REST server, and MCP server.
- Source: https://github.com/MotleyAI/slayer
